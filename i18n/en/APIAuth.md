# API Auth authentication flow using QR Code

**EN** | [PT](https://github.com/holyrics/Scripts/blob/main/APIAuth.md)

---


Utility method to receive a `payload` from an external service.<br>
Useful for logging in, receiving an authentication token.<br>
An active [Holyrics Plan](https://holyrics.com.br/holyrics_plan.html) subscription is required to use this option.<br>

A QR Code is displayed containing a `json` with the following information:
```json
{
    "type": "jslib_api_auth",
    "ts": "1779726247",
    "device": "hostname",
    "token": "ONuqkROS93wTAQgRljDQcZGg0hTCu3MADrAyzbp3YS5EN2HqebNsC0dnPTvL12xZ",
    "sig": "bca47d4a4f154c3f3be926f2e95bc9488642867706e9e3a17cf737f193ebb3ce"
}
```
`type` Type of authentication (for possible automatic identification of the type of QR Code scanned)<br>
`ts` timestamp in seconds<br>
`device` Computer name<br>
`token` string 64 characters [a-zA-Z0-9] Token generated by Holyrics for sending the authentication token over the internet<br>
`sig` Signature for simple verification of the QR Code's authenticity<br>

### sig
The value `sig` is an `HmacSHA256` of the concatenation `ts;device;token`, that is, based on the example `json` above it is:<br>
```json
"1779726247;hostname;ONuqkROS93wTAQgRljDQcZGg0hTCu3MADrAyzbp3YS5EN2HqebNsC0dnPTvL12xZ"
```
The value defined in the `secret` parameter is used to generate the `HmacSHA256`, in the example above the secret used was:<br>
```json
"EJbMZOnfEsZEal05T1OBqHnd3DqcYs1g"
```
It is optional, only if you want to validate the authenticity of the generated QR Code.

---

### After reading the QR Code and extracting the token, send the payload to the Holyrics endpoint
```bash
curl -X POST "https://holyrics.com.br/api/jslib_auth/send_payload.php" \
  -H "Content-Type: application/json" \
  -d '{
    "token":"ONuqkROS93wTAQgRljDQcZGg0hTCu3MADrAyzbp3YS5EN2HqebNsC0dnPTvL12xZ",
    "payload":"any content you need to send, authentication token, for example"
  }'
```
Note: The content sent in the payload can also be a complex object instead of a string.<br>
Maximum `payload` size: 1024 characters

### Possible error codes
400 invalid token or invalid payload<br>
401 token not found<br>
405 if the request is not POST<br>
410 authentication deadline expired<br>
422 if the token has already been used<br>

### After sending the payload to the endpoint
If the request from the previous step returns 200, the payload will be received internally by the Holyrics program open on the computer (and redirected to the `function callback`) and the window with the QR Code will be automatically closed.

Note: The window also displays a "copy" button, which copies the same JSON shown in the QR Code to the clipboard, but the content is in base64.<br>
Example:
```
eyJ0eXBlIjoianNsaWJfYXBpX2F1dGgiLCJ0cyI6IjE3Nzk3MjYyNDciLCJkZXZpY2UiOiJob3N0bmFtZSIsInRva2VuIjoiT051cWtST1M5M3dUQVFnUmxqRFFjWkdnMGhUQ3UzTUFEckF5emJwM1lTNUVOMkhxZWJOc0MwZG5QVHZMMTJ4WiIsInNpZyI6ImJjYTQ3ZDRhNGYxNTRjM2YzYmU5MjZmMmU5NWJjOTQ4ODY0Mjg2NzcwNmU5ZTNhMTdjZjczN2YxOTNlYmIzY2UifQ==
```
This is useful to allow the user to copy and paste the content in a location that does not have the option to read the QR Code, such as access through a desktop browser, for example.

Example code:
```javascript
function scriptAction(obj) {
    
    var header = "<html><div style='text-align:center;width:400pt'>"
                 + "Help text for the user to know what to do to read the QR Code";
    h.popupAPIAuth({
      window_title: 'QR Code Auth Test',
      header: header,
      callback: (payload) => {
        h.log("payload");
        h.logp(payload);
      },
      on_error: (err) => {
        h.log(err);
      },
      secret: 'EJbMZOnfEsZEal05T1OBqHnd3DqcYs1g'
    });
    
}
```
